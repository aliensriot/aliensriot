# aliensriot: сайт-витрина

Статический сайт: картины, украшения ручной работы (всё витрина, заказ через
Telegram), эко-проект only20dollars (секонд-хенд одежда и эко-аксессуары из
переработанных пакетов) и диджитал-товары (планеры, календари) с оплатой
через Продамус.

Файлы с содержимым:

```
index.html      : разметка и весь текст (RU/EN лежит в js/i18n.js)
css/style.css   : все стили
js/i18n.js      : тексты на русском и английском
js/main.js      : переключение языка
```

## Как посмотреть у себя

Просто откройте `index.html` в браузере. Никакой установки не нужно.

## Как выложить бесплатно на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `aliensriot-site`).
2. Загрузите в него все файлы этой папки (через веб-интерфейс GitHub
   "Add file → Upload files", или через `git push`, если умеете).
3. В репозитории откройте **Settings → Pages**.
4. В разделе "Build and deployment" выберите **Source: Deploy from a
   branch**, ветку `main` и папку `/ (root)`. Сохраните.
5. Через минуту-две сайт появится по адресу вида
   `https://<ваш-логин>.github.io/aliensriot-site/`.

Захотите свой домен вместо `github.io`, его можно будет прикрутить позже
через тот же раздел Pages (там есть поле "Custom domain"), домен придётся
купить отдельно, GitHub Pages сам его не продаёт.

## Как включить форму обратной связи (сейчас она никуда не отправляет)

Сайт статический, поэтому форма сама по себе письма не шлёт. Проще всего
подключить бесплатный сервис [Formspree](https://formspree.io):

1. Зарегистрируйтесь на formspree.io (можно через Google-почту).
2. Создайте новую форму, укажите почту, куда должны приходить сообщения.
3. Formspree даст адрес вида `https://formspree.io/f/xxxxabcd`.
4. В файле `index.html` найдите строку:
   ```html
   <form class="form" action="#" method="POST">
   ```
   и замените `action="#"` на `action="https://formspree.io/f/xxxxabcd"`
   (с вашим адресом).
5. Готово, письма с формы начнут приходить на почту.

Бесплатный тариф Formspree ограничен по числу сообщений в месяц, но для
личного сайта этого обычно достаточно с запасом.

## Как подключить оплату Продамус для диджитал-товаров

Сейчас в разделе "Диджитал-товары" три кнопки "Купить" ведут на `#`
(никуда). Как только будет создан аккаунт в Продамус:

1. Создайте в Продамус отдельный товар для каждого диджитал-продукта
   (планер, календарь и т.д.) с автоматической выдачей ссылки на скачивание
   после оплаты, это настраивается в самом Продамус.
2. Продамус даст ссылку на страницу оплаты для каждого товара.
3. В `index.html` найдите нужную карточку (`<article class="digital-card">`)
   и замените `href="#"` у кнопки "Купить" на ссылку от Продамус.

Если товаров станет больше, копируйте блок `<article class="digital-card">
… </article>` целиком и меняйте в копии текст, цену и ссылку.

## Как добавить свои фотографии

Сейчас вместо фото на сайте пунктирные плейсхолдеры (место под фото, с
подписью). Чтобы вставить настоящее фото:

1. Положите файл фотографии в папку `assets/` (например,
   `assets/koltso-1.jpg`).
2. В `index.html` найдите нужный блок `<div class="photo-slot">…</div>`
   и замените его целиком на:
   ```html
   <img src="assets/koltso-1.jpg" alt="Кольцо, серебро, бирюза" />
   ```
   (текст в `alt`, короткое описание фото для людей, которые его не видят).

## Как добавить карточку в любой из разделов

Каждый раздел устроен одинаково: один блок-карточка повторяется столько раз,
сколько нужно. Чтобы добавить ещё одну, скопируйте последний такой блок в
нужном разделе, вставьте его сразу после, замените фото и текст внутри.

| Раздел | Тег карточки | Где искать в `index.html` |
| --- | --- | --- |
| Украшения | `<article class="jewel-card">…</article>` | секция `id="jewelry"` |
| Картины | `<article class="painting-card">…</article>` | секция `id="paintings"` |
| only20dollars (секонд-хенд) | `<article class="thrift-card">…</article>` | секция `id="thrift"`, первая сетка |
| Эко-аксессуары из пакетов | `<article class="thrift-card">…</article>` | секция `id="thrift"`, блок `class="thrift-eco"` в конце |
| Диджитал-товары | `<article class="digital-card">…</article>` | секция `id="digital"` |

## Как поменять тексты

Весь видимый текст сайта (и русский, и английский) лежит в одном месте,
файле `js/i18n.js`. Найдите нужную строку по её смыслу (там понятные
названия ключей, например `"hero.lede"` или `"thrift.note"`) и поменяйте
текст внутри кавычек, и для русского, и для английского варианта отдельно.

## Аналитика посещений

Пока не подключена. Если понадобится (например, бесплатная Яндекс.Метрика),
добавьте код счётчика перед закрывающим тегом `</head>` в `index.html`.
